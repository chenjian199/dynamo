# M05 公共工具

[transfer](transfer/README.md) 集中管理 PD 服务、传输探针、拓扑覆盖、故障与长稳测试，以及按厂商源码摘要保护的补丁。它既包含引擎链路测试，也包含绕开引擎的底层传输对照。

先从 [M05](../README.md) 选择功能与 case，再决定需要哪个探针或补丁。补丁存在、单次传输成功与故障恢复认证是不同结论。
