# M01 公共工具

[discovery](discovery/README.md) 检查运行中的平台发现信息与启动约束。它复用 [平台启动工具](../../../platforms/README.md)，不负责创建所有厂商开发环境。

先按 [M01 功能契约](../README.md) 选择 case，再绑定节点与服务、运行检查，并将结果保存到对应 campaign。脚本执行成功仍需经过工作流证据认证。
