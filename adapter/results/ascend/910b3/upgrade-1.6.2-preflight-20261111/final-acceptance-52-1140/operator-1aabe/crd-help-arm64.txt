Usage of /crd-apply:
  -conversion-webhook-service-name string
    	Service name for CRD conversion webhooks
  -conversion-webhook-service-namespace string
    	Service namespace for CRD conversion webhooks
  -crds-dir string
    	Directory containing CRD YAML files (default "/opt/dynamo-operator/crds/")
  -kubeconfig string
    	Paths to a kubeconfig. Only required if out-of-cluster.
  -lpx-enabled
    	Install the experimental LPXGraphDeployment CRD
  -version string
    	Operator version to stamp on CRDs
