Usage of ./manager:
  -config string
    	Path to operator configuration file (required)
  -dgdr-default-image string
    	Default DGDR profiler image, put into DGDR spec.image when unset; empty derives dynamo-planner:<operator-version>
  -kubeconfig string
    	Paths to a kubeconfig. Only required if out-of-cluster.
  -operator-image string
    	Operator image used to deliver version-matched helper binaries for DGD overrides
  -operator-image-pull-policy string
    	Image pull policy for operator helper init containers (default "IfNotPresent")
  -operator-version string
    	Version of the operator (used in lease holder identity) (default "unknown")
  -zap-devel
    	Development Mode defaults(encoder=consoleEncoder,logLevel=Debug,stackTraceLevel=Warn). Production Mode defaults(encoder=jsonEncoder,logLevel=Info,stackTraceLevel=Error) (default true)
  -zap-encoder value
    	Zap log encoding (one of 'json' or 'console')
  -zap-log-level value
    	Zap Level to configure the verbosity of logging. Can be one of 'debug', 'info', 'error', 'panic' or any integer value > 0 which corresponds to custom debug levels of increasing verbosity
  -zap-stacktrace-level value
    	Zap Level at and above which stacktraces are captured (one of 'info', 'error', 'panic').
  -zap-time-encoding value
    	Zap time encoding (one of 'epoch', 'millis', 'nano', 'iso8601', 'rfc3339' or 'rfc3339nano'). Defaults to 'epoch'.
