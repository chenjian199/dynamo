## 口径与复现

```bash
python3 adapter/tools/change-stats.py > adapter/results/workflow/cpu-controls/20261105-finalization/change-stats.json
```

脚本使用独立临时 Git index，对比 `v1.5.1` 与当前候选工作树，不修改实际暂存区、不提交。纳入已跟踪文件改动、未忽略的 adapter 新文件及六个 adapter skill；排除未跟踪 reference、缓存和其它无关路径。本报告、统计 JSON 及其 sidecar 排除，避免自引用。原始文件明细见 [change-stats.json](results/workflow/cpu-controls/20261105-finalization/change-stats.json)。

源码口径是 `.py/.rs/.go/.sh/.c/.cpp/.cu/.h/.hpp` 的 Git 物理行差异，包含注释和空行，**不是去注释 SLOC，也不是工时**。替换通常记为一删一增；按最终树计差异，历史反复修改不累加。使用 rename detection，目录移动不视为重写。各类语言/大模块表与代码分类表是同一组文件的不同切面，不能再相加。

硬件故障定位、跨节点验证、环境修复和失败实验不能用代码行数完整反映；实际过程与验收边界见 [定版记录](workflow/finalization.md) 和 [验证记录](workflow/validation.md)。
