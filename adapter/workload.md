## 统计边界与复现

从仓库根目录执行：

```bash
python3 adapter/tools/change-stats.py > /tmp/dynamo-change-stats.json
```

工具使用临时 Git index，对比 `v1.5.1` 与当前候选工作树，不修改实际暂存区，不创建提交。它纳入所有已跟踪文件的工作树改动及 `adapter/` 下未被忽略的新文件；不纳入未跟踪的 `reference/`、缓存、构建目录和其它未跟踪路径。本报告本身从统计中排除，以免自引用。后续代码变化会使重跑结果变化。

源码口径为 `.py/.rs/.go/.sh/.c/.cpp/.cu/.h/.hpp`，包括注释和空行；属于 Git 物理行差异，不是去注释后的 SLOC。`adapter/` 内源码归入验证与配套脚本，产品目录中的测试也归入验证；`container/` 等目录中的脚本归入构建工具。按基线到当前树的最终差异计算，历史上反复修改同一行不会重复累加；目录改名使用 Git rename detection，不作为重写代码计算。

这些数字衡量交付规模，不能直接换算人日：硬件调试、多机测试、失败定位和未保留的实验并不由代码行数完整体现。M01–M07 是限定能力与配置下的阶段性验收，仍有记录在案的暂缓项；M08/M09 集群验证与 M10 新镜像最终验收继续按模块计划推进。
